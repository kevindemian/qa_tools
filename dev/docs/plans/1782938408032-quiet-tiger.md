## Workstream B — Auditoria por Feature (INTEGRATED-PLAN)

### Workflow por Feature (7 passos)

```
1. Mapeamento → rg -l <keyword> para achar todos os arquivos
2. Auditoria T1-T20 → 20 categorias (entry point, config, testes, etc.)
3. 7 Dimensões → Isolamento, Robustez, Boas Práticas, Implementação, Métricas, UX, Deep Test
4. Registro de Gaps → cada ❌ vira GAP com ID e severidade
5. Correção de Causa Raiz → zero workarounds, zero bypass (regras R1-R5)
6. Testes de Integração → criar/atualizar following padrão existente
7. Validação → tsc + vitest + lint antes de próxima feature
```

### Padrão de Testes de Integração

```typescript
// shared/__tests__/integration/<feature>.integration.test.ts
import fs from 'node:fs';
import os from 'node:os';
import path from 'node:path';

let TEST_DIR: string;

describe('Integration: [Feature Name]', () => {
    beforeEach(() => {
        TEST_DIR = fs.mkdtempSync(path.join(os.tmpdir(), 'integration-<feature>-'));
    });
    afterEach(() => {
        fs.rmSync(TEST_DIR, { recursive: true, force: true });
    });

    describe('FT-xxa: [comportamento]', () => {
        it('...', () => { /* test body */ });
    });
});
```

**Regras:** isolamento total (tmp dir + cleanup), fixtures via integration-helpers.ts, sem mocks de filesystem, sem dependência externa, cada sub-teste testa UM comportamento.
