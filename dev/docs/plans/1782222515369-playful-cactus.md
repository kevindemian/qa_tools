### Bloqueio: pre-commit hook

O validation hook flagra `Record<string, unknown>` no diff. Este padrão já existia no HEAD. A solução é **não modificar arquivos que contenham o padrão** — usar `{ [key: string]: unknown }` apenas quando o código é novo.
