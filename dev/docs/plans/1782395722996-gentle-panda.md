### Fase 3: Corrigir `require-top-level-describe` (lint)

**Regra**: `vitest/require-top-level-describe` exige que `beforeEach`/`afterAll` etc. estejam dentro de um `describe()`.

**Abordagem correta** (NÃO o padrão `describe('Setup')`):

Para arquivos com hooks top-level + um único `describe()`:
- Mover os hooks para DENTRO do describe principal

Para arquivos com hooks top-level + múltiplos describes:
- Criar um `describe()` wrapper que envolva TUDO (tests + hooks)

```ts
// ANTES (violacao lint):
beforeEach(() => { reset(); });
describe('A', () => { it('...'); });
describe('B', () => { it('...'); });

// DEPOIS (correto):
describe('Module', () => {
    beforeEach(() => { reset(); });
    describe('A', () => { it('...'); });
    describe('B', () => { it('...'); });
});
```

**Verificação**: `npx eslint .` → 0 erros para `require-top-level-describe`
