# Plano: Verificar e Corrigir Ferramentas de Auditoria

## Contexto

O projeto possui um sistema de auditoria robusto (SOP com 11 fases, 898 linhas). Antes de continuar qualquer auditoria de features, é necessário garantir que todas as ferramentas estão instaladas, configuradas e corretamente declaradas.

---

## Problemas Encontrados

### CRÍTICO — Dependências não declaradas em package.json

| Pacote | Versão instalada | Status npm | Impacto |
|--------|-----------------|------------|---------|
| `eslint-plugin-sonarjs` | 4.1.0 | **extraneous** | `npm ci` quebra ESLint |
| `eslint-plugin-unused-imports` | 4.4.1 | **extraneous** | `npm ci` quebra ESLint |

Ambos são importados em `eslint.config.mjs` (linhas 10-11) mas **não existem** em `devDependencies`.

### MEDIUM — Configurações com problemas

| Arquivo | Problema | Linha |
|---------|----------|-------|
| `tsconfig.json` | Chave duplicada `"noPropertyAccessFromIndexSignature"` fora de `compilerOptions` | 25 |
| `tsconfig.build.json` | Referência a `shared/types/ambient.d.ts` que não existe | 10 |
| `jest.config.js` | Config morta — projeto usa vitest, jest não está nas deps | -- |

### Ferramentas obsoletas a substituir

| Pacote a remover | Substituto | Status do substituto | Config do substituto |
|------------------|------------|---------------------|---------------------|
| `madge` ^8.0.0 | `dependency-cruiser` | v18.0.0 instalado (extraneous) | `.dependency-cruiser.js` existe |
| `ts-prune` ^0.10.3 | `knip` | v6.21.0 instalado (extraneous) | `knip.json` existe |
| `snyk` ^1.1305.1 | `npm audit` | built-in | -- |

---

## Plano de Correção

### Passo 1 — Corrigir package.json: dependências CRÍTICAS

Adicionar os 2 plugins ESLint ausentes ao `devDependencies`:

```json
"eslint-plugin-sonarjs": "^4.1.0",
"eslint-plugin-unused-imports": "^4.4.1"
```

**Arquivo:** `package.json:58-84`

### Passo 2 — Corrigir package.json: substituir ferramentas obsoletas

Remover de `devDependencies`:
- `"madge": "^8.0.0"`
- `"ts-prune": "^0.10.3"`
- `"snyk": "^1.1305.1"`

Adicionar a `devDependencies`:
```json
"dependency-cruiser": "^18.0.0",
"knip": "^6.21.0"
```

**Arquivo:** `package.json:58-84`

### Passo 3 — Atualizar script `unused-exports` no package.json

Trocar de:
```json
"unused-exports": "ts-prune -p tsconfig.json | grep -v \"(used in module)\" || true"
```

Para:
```json
"unused-exports": "knip --reporter compact"
```

**Arquivo:** `package.json:16`

### Passo 4 — Atualizar `scripts/check-unused-exports.sh`

Reescrever o script para usar `knip` em vez de `ts-prune`. O knip já possui configuração em `knip.json` com entry points e project paths definidos.

**Arquivo:** `scripts/check-unused-exports.sh`

### Passo 5 — Atualizar `scripts/audit/sop-audit.sh` D12.1

Trocar de:
```bash
"npx madge --circular $src 2>&1 | grep -E '^[a-z]' || true"
```

Para:
```bash
"npx dep-cruise --no-embedded --ts-pre-compilation-deps --config .dependency-cruiser.js $src 2>&1 | grep -E '^(err|error)' || true"
```

**Arquivo:** `scripts/audit/sop-audit.sh:414-415`

### Passo 6 — Atualizar `audit/functional/SOP.md` referências

| Linha | De | Para |
|-------|-----|------|
| 219 | `npx ts-prune --project tsconfig.json \| grep "${FEATURE_NAME}"` | `npx knip --reporter compact \| grep "${FEATURE_NAME}"` |
| 406 | `npx madge --circular SOURCE 2>&1 \| grep -E '^[a-z]'` | `npx dep-cruise --no-embedded --config .dependency-cruiser.js SOURCE 2>&1 \| grep -E '^(err\|error)'` |

**Arquivo:** `audit/functional/SOP.md:219,406`

### Passo 7 — Corrigir tsconfig.json (MEDIUM)

Remover a chave duplicada na linha 25:
```json
"noPropertyAccessFromIndexSignature": true,
```
Esta linha está fora de `compilerOptions` — é uma chave morta. A chave já existe dentro de `compilerOptions` na linha 17.

**Arquivo:** `tsconfig.json:25`

### Passo 8 — Corrigir tsconfig.build.json (MEDIUM)

Remover `shared/types/ambient.d.ts` do array `include` (linha 10) — arquivo não existe.

**Arquivo:** `tsconfig.build.json:10`

### Passo 9 — Deletar jest.config.js (MEDIUM)

Config morta. O projeto usa vitest, jest/ts-jest não estão nas dependências.

**Arquivo:** `jest.config.js`

### Passo 10 — Instalar dependências

```bash
npm install
```

### Passo 11 — Validação

```bash
npm run typecheck          # 0 erros
npm run lint               # 0 violações
npm run unused-exports     # knip funciona corretamente
npm run test               # todos passam
npm run build              # sucesso
npx dep-cruise --circular shared/  # 0 circulares
```
