### 1. Corrigir sop-audit.sh

**Arquivo:** `scripts/audit/sop-audit.sh`

**Bug:** Linha 230 usa `${SOURCE:-$SEARCH_SOURCE}` mas `SEARCH_SOURCE` só é setada com `--all`. Linha 238 verifica `[[ -z "$src" && -z "$SEARCH_SOURCE" ]]` que é redundante.

**Fix:**
- Linha 238: mudar para `[[ -z "$src" ]]`
- Manter `SEARCH_SOURCE=""` na linha 24 (inicialização)
- A lógica atual funciona para `--all` (SEARCH_SOURCE setada) e `--feature` (SOURCE setada), mas o check na linha 238 é confuso
