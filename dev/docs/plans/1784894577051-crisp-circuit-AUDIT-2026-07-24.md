### Impacto
1. **Legal**: Emojis Unicode são grafismos protegidos por copyright de fabricantes (Apple, Google, etc.)
2. **Profissional**: Emojis em relatórios corporativos são visualmente inconsistentes entre SOs
3. **Acessibilidade**: Screen readers tratam emojis de forma inconsistente
4. **Consistência**: O plano previa Lucide SVG para uniformidade

### Solução necessária
Criar `shared/icons.ts` com SVG inline inspirado no Lucide, e substituir TODOS os emojis por ícones SVG.

### Resumo da Recomendação de Ícones

| Formato | Solução | Arquivo |
|---------|---------|---------|
| **HTML dashboards** | `lucide` npm + import individual (~20 ícones, tree-shaken) | `shared/icons.ts` (wrapper) |
| **Markdown PR comment** | Unicode symbols (`✓` `✗` `△` `→`) | Inline em pr-report-core.ts |
| **CLI output** | Unicode symbols | Inline em pr-report-core.ts |

**Por que Lucide:**
- Sucessor oficial do Feather (mesmo design stroke-based 24×24)
- Consistente com SVG charts existentes (BarChart, TrendChart, Sparkline)
- ~1500 ícones MIT, tree-shakeable via ESM
- Peso idêntico ao manual (~4.5KB para ~20 ícones), manutenção zero
- TypeScript types automáticos

**`shared/icons.ts` wrapper (não SVGs manuais):**
```typescript
import { CheckCircle, XCircle, AlertTriangle, ... } from 'lucide';

// Serializa componente Lucide para SVG string inline
export function icon(name: IconName, size?: number): string {
    const Component = ICON_MAP[name];
    return renderToSvgString(Component, size);
}
```
