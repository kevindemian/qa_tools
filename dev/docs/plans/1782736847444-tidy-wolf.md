## Plano de Verificação

### Fase 1: Verificação de Instalação
1. Verificar se `node_modules/` existe e está completo
2. Verificar versões instaladas vs package.json
3. Verificar se ferramentas CLI externas estão disponíveis (gitleaks, osv-scanner)

### Fase 2: Verificação de Configuração
1. Validar `eslint.config.mjs` - sintaxe e plugins
2. Validar `.prettierrc` - regras de formatação
3. Validar `tsconfig.json` - flags strict
4. Validar `knip.json` - entry points e globs
5. Validar `.dependency-cruiser.js` - regras de camadas
6. Validar `.gitleaks.toml` - regras customizadas
7. Validar `vitest.config.ts` - thresholds de cobertura

### Fase 3: Verificação de Integração Git Hooks
1. Verificar se Husky está instalado e hooks são executáveis
2. Testar pre-commit hook (simular staging)
3. Verificar lint-staged está configurado corretamente
4. Verificar lockfile-lint está integrado

### Fase 4: Verificação de Integração CI
1. Verificar se workflows estão sintaticamente válidos
2. Verificar se todos os scripts npm referenciados existem
3. Verificar matrix de Node.js (22, 24)
4. Verificar upload de artifacts (CTRF reports)

### Fase 5: Verificação de Execução
1. Rodar `npm run typecheck` - deve passar sem erros
2. Rodar `npm run lint` - deve passar sem erros
3. Rodar `npm test` - deve passar com cobertura
4. Rodar `npm run unused-exports` - deve passar
5. Rodar `npm run depcruise` - deve passar
6. Rodar `npm run type-coverage` - deve atingir 90%

## Comandos de Verificação

```bash
# Fase 1: Instalação
ls -la node_modules/.package-lock.json
npm ls --depth=0
which gitleaks
which osv-scanner

# Fase 2: Configuração
npx eslint --print-config file.ts
npx prettier --check .
npx tsc --showConfig

# Fase 3: Git Hooks
ls -la .husky/
cat .husky/pre-commit
npx lint-staged --version

# Fase 4: CI
cat .github/workflows/ci.yml | head -50
cat .github/workflows/ci-quality.yml | head -50

# Fase 5: Execução
npm run typecheck
npm run lint
npm test
npm run unused-exports
npm run depcruise
npm run type-coverage
```
