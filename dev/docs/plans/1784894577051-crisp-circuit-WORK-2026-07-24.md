1. **Escopo exclusivo:** Fase 2 — extração dos 7 quality renderers. Nenhuma etapa futura.

3. **Safeguard clauses:** TODA função que processa input externo ou dados numéricos DEVE ter guards explícitos (NaN, null, undefined, empty).
4. **Zero catches vazios:** TODO catch DEVE logar causa, forma de correção e capacidade de retomada.
5. **Resiliência:** O sistema DEVE ser resiliente. Hard fail sem contexto é proibido.
6. **Código obsoleto:** Em refatorações, apagar COMPLETAMENTE o código obsoleto.
7. **Superioridade técnica:** Decisões técnicas seguem unicamente superioridade técnica e segurança. Tempo/esforço NÃO são variáveis.
8. **Erros existentes:** TODO erro na árvore de execução DEVE ser corrigido. Não existem "fora de escopo".

### Testes e Qualidade
1. **Anti-mock theater:** Mocks EXCLUSIVAMENTE para fronteiras de infraestrutura externa (APIs de terceiros, redes HTTP). Lógica local roda de verdade.
2. **Test-first:** Criar testes correspondentes (unidade, integração) ANTES ou DURANTE a extração.
3. **Negativos e edge cases:** Priorizar testes negativos e edge cases.
4. **Bug = código:** Se teste falhar, o BUG ESTÁ NO CÓDIGO-FONTE. Proibido alterar asserts.

### Deploy
