## Phase 2: Redundancy & Risk Analysis

### 2.1 Redundancies (candidates for removal)

| Current Tool | Redundant With | Recommendation |
|-------------|---------------|----------------|
| `lint-staged` (pre-commit) | `quality-check.ts` (pre-push) | **KEEP** — lint-staged provides fast incremental feedback; quality-check is full codebase. Different purposes. |
| `sonarqube-scanner` (local) | `eslint-plugin-sonarjs` (local) | **REMOVE** sonarqube-scanner from devDeps — sonarjs ESLint plugin covers local analysis. Scanner needs SONAR_TOKEN, only useful in CI. |
| `jest.config.js` | `vitest.config.ts` | **REMOVE** — dead config, no tests use jest |
| `madge` (declared, not installed) | `knip` + `depcruise` | **REMOVE** declaration from package.json |
| `ts-prune` (declared, not installed) | `knip` | **REMOVE** declaration from package.json |
| `snyk` (declared, not installed) | `osv-scanner` | **REMOVE** declaration from package.json |
| `semgrep` (installed, unused) | quality-check.ts + validation_hook.ts | **EVALUATE** — semgrep has unique rules not covered by existing tools, but requires integration effort |

### 2.2 Risks Identified

| Risk | Impact | Mitigation |
|------|--------|------------|
| eslint-plugin-sonarjs/unused-imports not declared in package.json | **CRITICAL** — `npm ci` fails on clean install | Add to devDependencies |
| husky/lockfile-lint not declared in package.json | **MEDIUM** — npm ci installs wrong versions | Add to devDependencies |
| validation_hook.ts disconnected from active hooks | **HIGH** — safety engine runs on zero commits | Either migrate to .husky/ or switch core.hooksPath |
| No commit-msg validation in active hooks | **MEDIUM** — bad commit messages pass unchecked | Add .husky/commit-msg or switch to .githooks/ |
| .only() detection missing from pre-commit | **LOW** — caught by pre-push test run | Add grep check to .husky/pre-commit |
| tsconfig.build.json references nonexistent file | **MEDIUM** — build may fail if file is referenced | Remove the reference |
| tsconfig.json duplicate key | **LOW** — TypeScript uses last occurrence, but confusing | Remove duplicate |
| semgrep installed but unused | **LOW** — wasted disk space, no security benefit | Integrate or remove |
