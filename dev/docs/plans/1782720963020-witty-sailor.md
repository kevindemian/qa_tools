### Gaps Críticos Identificados

#### GAP 1: Sistema Dual de Hooks — Apenas Husky Ativo
- `.githooks/` contém hooks completos (typecheck, validation hook, rule-vigilant, quality-check, tests, security scan)
- Mas `core.hooksPath` aponta para `.husky/_` (apenas lint-staged + lockfile-lint)
- **Impacto:** Pre-push hook (quality-check, tests, security scan) está completamente inativo

#### GAP 2: CI Executa quality-check duas vezes
- `ci.yml` e `ci-quality.yml` disparam no mesmo evento (push/PR to main)
- Ambos rodam `npm run lint` (quality-check.ts)
- **Impacto:** Redundância, custo CI desnecessário

#### GAP 3: publish.yml Usa Jest, Não Vitest
- `publish.yml` roda `npx jest --coverage`
- Projeto usa vitest
- **Impacto:** Pode falhar se jest não estiver instalado

#### GAP 4: Knip ignoreDependencies Vazio
- DepWall packages (`cliProgress`, `CliTable3`, `figlet`, etc.) são falsos positivos
- Devem estar em `ignoreDependencies` no knip.json
- **Impacto:** Relatórios de unused deps incorretos

#### GAP 5: SonarQube Coverage Path Incorreto
- `sonar-project.properties` referencia `coverage/lcov.info`
- Vitest usa provider v8 (gera `coverage-final.json`)
- **Impacto:** SonarQube CI não recebe dados de coverage

#### GAP 6: quality-check.ts Severity Filter
- Linha 97: `msg.severity >= 1` conta warnings como violações
- Deveria ser `msg.severity === 2` (apenas errors)
- **Impacto:** Quality gate mais restritivo que o planejado

#### GAP 7: Sem .prettierignore
- Prettier pode formatar arquivos indesejados (dist/, coverage/)
- **Impacto:** Menor, mas inconsistente

#### GAP 8: jest.config.js é Config Morta
- Projeto usa vitest, mas jest.config.js ainda existe
- **Impacto:** Confusão, manutenção desnecessária

#### GAP 9: package.json Discrepâncias
- `eslint-plugin-sonarjs` e `eslint-plugin-unused-imports` importados mas não declarados
- `husky` e `lockfile-lint` instalados mas não declarados
- **Impacto:** `npm ci` pode quebrar

#### GAP 10: Scripts CI Referenciam Comandos Não Definidos
- `ci-quality.yml` chama `npm run depcruise`, `npm run type-coverage`, `npm run gitleaks`, `npm run osv-scan`
- Esses scripts não existem em package.json
- **Impacto:** CI jobs vão falhar

## Plano de Correção

### Fase 1: package.json (Prioridade Alta)
1. Remover mortas: `madge`, `ts-prune`, `snyk`
2. Adicionar fantasma: `knip` como devDependency
3. Adicionar ausentes: `depcruise`, `type-coverage`, `lockfile-lint`
4. Declarar plugins ESLint: `eslint-plugin-sonarjs`, `eslint-plugin-unused-imports`
5. Declarar `husky`, `lockfile-lint`
6. Adicionar scripts faltantes: `depcruise`, `type-coverage`, `gitleaks`, `osv-scan`

### Fase 2: Hooks (Prioridade Alta)
1. Decidir: Husky ou .githooks/? (recomendado: mesclar .githooks/ essenciais no Husky)
2. Adicionar pre-push hook no Husky com: typecheck → quality-check → tests
3. Adicionar commit-msg hook no Husky com: validation hook check

### Fase 3: Configurações (Prioridade Média)
1. knip.json: adicionar `ignoreDependencies` para DepWall packages
2. sonar-project.properties: corrigir coverage path para v8
3. Criar .prettierignore
4. Remover jest.config.js
5. Corrigir quality-check.ts severity filter

### Fase 4: CI (Prioridade Média)
1. Consolidar ci.yml e ci-quality.yml (evitar duplicação)
2. Corrigir publish.yml: jest → vitest
3. Verificar que todos os scripts referenciados existem
