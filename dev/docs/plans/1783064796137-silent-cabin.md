# Dependabot → Security-only + script de updates

## Visão geral

Eliminar dependabot regular updates e auto-merge. Manter security updates. Criar script local que avisa sobre updates disponíveis no pre-commit (warning, não bloqueador).

## Passo 1: Limpar branches stale

Executar via gh CLI para fechar PRs abertos e deletar branches remotas:

```bash
gh pr list --author "dependabot[bot]" --state open --json number --jq '.[].number' | xargs -I {} gh pr close {} --comment "Superseded: security-only policy"
git fetch --prune
git branch -r | grep dependabot | sed 's|origin/||' | xargs -I {} git push origin --delete {}
```

## Passo 2: Deletar auto-merge workflow

Remover `.github/workflows/dependabot-auto-merge.yml`.

## Passo 3: Simplificar dependabot.yml

Edição de `.github/dependabot.yml`:

```yaml
version: 2
updates:
  - package-ecosystem: 'npm'
    directory: '/'
    open-pull-requests-limit: 0
    schedule:
      interval: 'weekly'
      day: 'monday'
      time: '09:00'
      timezone: 'America/Sao_Paulo'
    commit-message:
      prefix: 'chore'
      prefix-development: 'chore'
      include: 'scope'
```

Removidos: `versioning-strategy`, `cooldown`, `groups`, `labels`.

## Passo 4: Script de updates disponíveis

Criar `scripts/check-updates.sh`:

```bash
#!/usr/bin/env bash
# Check for available dependency updates (informational only).
# Runs in pre-commit as a WARNING — never blocks commits.

OUTDATED=$(npm outdated --json 2>/dev/null)
if [ -z "$OUTDATED" ] || [ "$OUTDATED" = "{}" ]; then
    echo "✅ All dependencies up to date."
    exit 0
fi

COUNT=$(echo "$OUTDATED" | grep -c '"wanted"' || echo "0")
echo ""
echo "📦 ${COUNT} update(s) available. Run 'npm outdated' for details."
echo ""
```

Exit code 0 sempre — é warning, não blocker.

## Passo 5: Integrar no pre-commit hook

Adicionar ao `.husky/pre-commit`, antes do lint-staged:

```bash
# Dependency update check (informational)
if [ -f scripts/check-updates.sh ]; then
    echo "--- Dependency updates ---"
    bash scripts/check-updates.sh
fi
```

## Passo 6: Integrar no pre-push hook

Adicionar ao `.husky/pre-push` (após typecheck, antes de testes):

```bash
# Dependency update check before push
if [ -f scripts/check-updates.sh ]; then
    echo "--- Dependency updates ---"
    bash scripts/check-updates.sh
fi
```
