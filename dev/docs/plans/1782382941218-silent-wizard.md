### 3.3 `detect-non-literal-fs-filename` (399 warnings)

**Mecanismo da regra**: `isStaticExpression()` reconhece como "static": Literals, `path.join()` com args estáticos, `import.meta.dirname`, `process.cwd()`, `__dirname`, `require.resolve()`. NÃO reconhece: variáveis dinâmicas, parâmetros de função, return values.

**Breakdown real**:
- 70 violações: `fs.*(path.join(dynamicArg, ...))` — primeiro arg de `path.join` é dinâmico
- 279 violações: `fs.*(dynamicVar)` — variável direta
- 50+ violações em source files com paths construídos via Config/parâmetros

**Estratégia de refatoração**:
1. **Test files (179)**: Criar paths relativos a `import.meta.dirname` do arquivo de teste
   - Substituir `os.tmpdir()` por `path.join(import.meta.dirname, '__tmp__')` 
   - Substituir variáveis de tmp por construção com `import.meta.dirname`
2. **Source files (220)**: Refatorar cadeia de chamadas para construir paths com `import.meta.dirname`
   - Funções que recebem `filePath` → caller passa `path.join(import.meta.dirname, ...)`
   - `Config.get()` retorna paths → Config internamente usa `import.meta.dirname`
   - `os.homedir()` → `import.meta.dirname` relativo quando possível

**Restrição**: validation hook bloqueia `Record<string, unknown>` e `as unknown as`. Usar index signatures `{ [key: string]: unknown }` e refatoração de tipos.

### 3.4 `detect-object-injection` (409 warnings)

**Breakdown**: 372 obj/array indexing, 36 process.env, 1 config

**Estratégia**:
1. **`process.env` (36)**: `process.env[key]` → tipar com interface `NodeJS.ProcessEnv` ou usar `as string` após verificação
2. **Obj indexing (372)**: Converter `Record<string,T>` para `Map<string,T>` onde o indexador é dinâmico
   - Arrays com index dinâmico (`matrix[i]`, `lines[i]`) → são seguros por natureza, mas regra flaga
   - Para arrays: usar `Array<T>` tipado e indexer com number (se aplicável)
   - Para objetos: converter para `Map<string,T>`
3. **Cascading**: converter Record→Map requer alterar todos os call sites
