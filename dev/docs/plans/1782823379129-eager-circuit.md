## 1. D7 Bad Testing — 1 FAIL (Regex Bug)

**Arquivo:** `scripts/audit/d7-bad-testing.sh:167`

**Bug:** `toThrow\(\s*\)` casa `.not.toThrow()` (que é válido — afirma ausência de exceção).

**Fix:** Usar lookbehind negativo para excluir `.not.toThrow()`:
```bash
# ANTES (bug):
'toThrow\(\s*\)'

# DEPOIS (correto):
'(?<!\.not\.)toThrow\(\s*\)'
```

**Validação:** `bash scripts/audit/d7-bad-testing.sh --all` → D7.5 PASS

## 2. SOP Audit — 45 FAIL

**Arquivo:** `scripts/audit/sop-audit.sh`

**Problema:** O script usa grep semântico que gera falsos positivos. O script é ferramenta de detecção para auditoria humana, não gate de CI.

**Fixes necessários:**

### 2.1 Excluir paths irrelevantes
Linha 22 — adicionar `--exclude-dir=coverage`, `--exclude-dir=reports`, `--exclude-dir=docs`, `--exclude-dir=internal_docs`, `--exclude-dir=data`

### 2.2 Ajustar regex de parameter reassignment
A regex atual é muito ampla. Ajustar para ser mais precisa (capturar apenas reatribuição real de parâmetros, não destructuring ou alias).

### 2.3 Adicionar contexto de teste
Várias verificações (0.1.5 I/O sem try/catch, 0.1.10 DepWall, 0.1.12 Magic constants) misturam código de produção com testes. Adicionar filtros para linhas que são claramente de teste (contendo `vi.mock`, `vi.fn`, `describe(`, `it(`).

### 2.4 Corrigir SEARCH_SOURCE
Linha 228 — `SEARCH_SOURCE` só é definido quando `--all` é usado. Adicionar inicialização padrão.

**Validação:** `bash scripts/audit/sop-audit.sh --all` → FAIL count reduz significativamente
