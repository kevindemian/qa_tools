# Plano: Correção da integração CiDataHub nos consumidores

## Problema

O PR report (job summary + PR comment) mostra métricas incorretas: 2 testes em vez de 5833. O HTML report embutido tem os dados corretos. A causa raiz é que `CiDataHub` nunca é criado nem passado nos pontos de entrada de produção.

## Plano de correção

### Passo 1: `pr-report-core.ts` main() — criar CiDataHub quando em CI

Em `main()` (linha ~681), após detectar `ciEnv.isCI`:

```typescript
let ciData: CiDataHub | undefined;
if (ciEnv.isCI && process.env['GITHUB_TOKEN']) {
    try {
        const { createCiDataHub } = await import('./ci-data.js');
        const { GitHubManager } = await import('./github-api.js');
        const token = process.env['GITHUB_TOKEN'];
        const [owner, repo] = ciEnv.repo.split('/');
        if (owner && repo) {
            const provider = new GitHubManager(token, owner, repo);
            ciData = await createCiDataHub(provider, ciEnv.repo);
        }
    } catch (err) {
        rootLogger.warn(`CiDataHub creation failed: ${String(err)}`);
    }
}
```

Passar `ciData` para `generatePrReport()`.

**Arquivo:** `shared/pr-report-core.ts`
**Verificação:** Criar `GitHubManager` com o token disponível; se falhar, logar warning e prosseguir sem ciData (fallback para MetricsStore).

### Passo 6: Helper compartilhado para criação de CiDataHub

Criar em `shared/ci-data.ts` uma função de conveniência:

```typescript
let _cachedHub: CiDataHub | undefined;
export async function getOrFetchCiDataHub(provider: GitProvider, repo: string): Promise<CiDataHub | undefined> {
    if (_cachedHub && _cachedHub.repo === repo) return _cachedHub;
    try {
        _cachedHub = await createCiDataHub(provider, repo);
        return _cachedHub;
    } catch {
        return undefined;
    }
}
```

Cache simples evita múltiplas chamadas à API na mesma sessão.

**Arquivo:** `shared/ci-data.ts`

### Correção necessária nos testes

Cada teste "ciData not yet consumed" precisa ser invertido para testar o comportamento correto:

**health-score:**
```typescript
it('ciData passRate overrides MetricsStore when provided', () => {
    const store = createStore({ passed: 50, failed: 50 }); // 50% no MetricsStore
    const hub = makeCiHub({ passRate: 90 });               // 90% no CiDataHub
    const result = calculateHealthScore(store, { ciData: hub });
    expect(result.dimensions.passRate.score).toBe(90);      // DEVE usar ciData
});
```

**quality-gate:**
```typescript
it('ciData changes quality gate result when MetricsStore is empty', () => {

    const hub = makeCiHub({ passRate: 100 });

    const withoutCi = runQualityGate();
    expect(withCi.overall).not.toBe(withoutCi.overall);  // DEVE diferir
});
```

**ci-data.integration.test.ts:**
```typescript
it('health score uses ciData passRate instead of MetricsStore', async () => {
    const hub = await createCiDataHub(provider, 'owner/repo');
    const store = createStore({ passed: 10, failed: 90 }); // 10% local

    expect(result.dimensions.passRate.score).toBeCloseTo(66.67, 0); // 66.67% do hub
```
