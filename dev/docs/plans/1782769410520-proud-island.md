## Part A: Fix 18 Test Failures (3 files, 3 root causes)

### A1. `shared/logger.test.ts` — 12 failures

**Root cause A (6 failures):** Tests spy on `console.log`/`console.error` but Logger uses `process.stdout.write`/`process.stderr.write`.
- **Fix:** Replace `vi.spyOn(console, 'log')` and `vi.spyOn(console, 'error')` with spies on `process.stdout.write` and `process.stderr.write`.
- Adjust assertions to match the new spy's string format.

**Root cause B (6 failures):** `Reflect.get(logger, level)(msg, data)` extracts method without `this`.
- **Fix:** Use `logger[level](msg, data)` directly instead of `Reflect.get`.

### A2. `scripts/opencode-db-maintenance.test.ts` — 4 failures

**Root cause:** Same as logger — tests spy on `console.log` but `printResult()` uses `rootLogger.info()`.
- **Fix:** Spy on `rootLogger.info` instead of `console.log`.

### A3. `shared/state.test.ts` — 2 failures

**Root cause:** Test uses `os.homedir()` for `OLD_STATE_PATH` but implementation uses `import.meta.dirname`.
- **Fix:** Update test to use `import.meta.dirname` (or import the same path constant from the implementation).

## Part B: Fix 534 ESLint Errors (28 rules)

### B1. `sonarjs/publicly-writable-directories` — 185 errors

**Nature:** Tests using `os.tmpdir()` or `/tmp` for test fixtures.
**Fix approach:** These are in test files. The rule flags writing to publicly-writable directories. For test fixtures:
- Use `vitest`'s `vi.tmpdir()` or create a unique temp subdirectory per test run
- OR use `import.meta.dirname` + `.tmp/` relative to test file
- Assess each file to determine the minimal-change fix
