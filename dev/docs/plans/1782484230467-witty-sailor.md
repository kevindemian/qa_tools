## Itens Críticos a Corrigir

### 1. ERRO ESLint: `git_triggers/batch-mode.ts:90`

```
@typescript-eslint/no-unnecessary-condition
Unnecessary conditional, expected left-hand side of `??` operator to be possibly null or undefined
```

**Linha 90:**
```typescript
const projectName = (batch.project || (firstEntry ? firstEntry[0] : '')) ?? '';
```

**Problema:** `batch.project` é `string | undefined`. O operador `||` já retorna `string` (porque o fallback é `''`). O `??` é redundante.

**Fix:** Remover `?? ''`:
```typescript
const projectName = batch.project || (firstEntry ? firstEntry[0] : '');
```

### 2. TESTE falhando: `shared/metrics.test.ts:433`

```
expect(loaded.runs).toHaveLength(1)
Expected: 1, Received: 2
```

**Teste:** Chama `saveRunMetrics(run, cfg)` duas vezes com o mesmo run, espera deduplicação.

**Implementação (`shared/metrics.ts:154`):** Apenas faz `push` sem verificar duplicatas.

**Raiz:** A implementação deveria deduplicar runs (por timestamp+project ou similar), mas não faz.

**Fix necessário:** Adicionar lógica de deduplicação em `saveRunMetrics` antes do push:
```typescript
const key = `${run.timestamp}::${run.project}`;
store.runs = store.runs.filter(r => `${r.timestamp}::${r.project}` !== key);
store.runs.push(run);
```
