### Padrão de fix

**Regra do lint**: `isStaticExpression()` reconhece como "static":
- Literais
- `path.join()` com args estáticos
- `import.meta.dirname`
- `process.cwd()`
- `__dirname`
- `__filename`
- `require.resolve()`

**NÃO reconhece**:
- `os.homedir()`
- `os.tmpdir()`
- Parâmetros de função
- `Config.get()`

**Fix patterns**:
1. `os.homedir()` → `import.meta.dirname` ou `process.cwd()`
2. `os.tmpdir()` → `path.join(import.meta.dirname, '__tmp__')`
3. Variáveis rastreadas até `path.join(import.meta.dirname, ...)` → funciona

### Estratégia
1. Processar arquivos de maior contagem primeiro
2. Para cada arquivo: identificar o padrão de path, aplicar fix apropriado
3. Verificar com `npx eslint <arquivo>` após cada fix
4. A cada ~50 fixes: commit incremental
