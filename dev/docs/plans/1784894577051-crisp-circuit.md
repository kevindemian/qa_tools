## REGRAS GERAIS (valem para TODAS as fases)

1. **Protocolo de commit:** `npx eslint <arquivos>` → `npx tsc --noEmit` → `npx vitest run` → commit
2. **SSOT:** TODOS os artefatos consomem de DataHub. NENHUM calcula próprios dados
3. **Mocks:** APENAS para infraestrutura (API, filesystem). NUNCA para lógica de negócio
4. **Test failures = code bugs:** Nunca alterar asserts existentes
5. **Zero stubs/TODOs/placeholders:** Código 100% funcional
6. **Zero catches vazios:** Logs com causa, correção e retomada
7. **Safeguard clauses:** Toda função de input numérico/externo tem guards
8. **Não deferir:** Tudo implementado, zero parcialização
9. **Plano é fonte de verdade:** ANTES de cada tarefa, LER este arquivo. Identificar tarefa exata. NUNCA confiar em memória.
10. **Verificação obrigatória:** Nenhuma tarefa é marcada completa sem rodar a verificação definida nela
